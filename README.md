# Veyra downloads

Installers for **Veyra: Pebble Mind Skills Check**, made by Schologists Magna Ltd.

Most people should download it from **https://veyra.org.uk/play/**, which explains how to install it and where to find it afterwards.

This repository holds release files only; it contains no source code. Every installer is signed with the Schologists Magna Ltd code-signing certificate, and each release lists its SHA-256 fingerprint so you can check the file.

Questions: https://veyra.org.uk/contact/
